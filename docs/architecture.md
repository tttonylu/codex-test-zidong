# BPlus 架构说明

## 四层结构

### 1. NAS 总控层

职责：

- 终端注册
- 实例总览
- 策略分发
- 任务编排
- 统计与审计

### 2. 终端代理层

职责：

- 本机 BitBrowser 扫描
- 实例映射维护
- 本机动作执行
- 本机状态缓存
- 与 NAS 通信

### 3. 实例运行层

职责：

- 管理账号实例状态
- 管理实例与脚本绑定
- 对接窗口与 profile

### 4. 脚本执行层

职责：

- follow/chat/probe 等脚本执行
- 向实例层回报结果

## 三条流

### 状态流

`脚本 -> 实例 -> 终端代理 -> NAS`

### 控制流

`NAS -> 终端代理 -> 实例 -> 脚本`

### 回执流

`脚本 / 实例 / 终端代理 -> NAS`

## 核心原则

- 终端是矩阵节点
- 实例是标准工作单元
- 脚本不是调度器
- 页面不是主框架
